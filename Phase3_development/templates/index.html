About This Tool

How It Works

This phishing detection tool uses a Logistic Regression Classifier wrapped in CalibratedClassifierCV (sigmoid, 5-fold CV), trained on a hybrid feature space of 5,020 features (5,000 TF-IDF terms over the email body plus 20 handcrafted phishing indicators). The model analyses:

  • URL Analysis - IP-literal hosts, URL shorteners, suspicious TLDs, brand-subdomain spoofing
  • Text Features - TF-IDF over email body, urgency and credential-request keywords
  • Authentication - Header anomalies, reply-to mismatch, free-webmail sender flag
  • Domain Analysis - Lookalike detection, sender-reputation allowlist + hard-signal escalation
