About This Tool

How It Works

This phishing detection tool uses a Random Forest Classifier trained on real-world email data from the Kaggle dataset. The model analyzes 27 distinct features including:

  • URL Analysis - Detects suspicious links and shortened URLs
  • Text Features - Identifies urgency keywords and phishing language
  • Authentication - Checks email headers (DKIM, SPF, DMARC)
  • Domain Analysis - Verifies sender domains and identifies spoofing
